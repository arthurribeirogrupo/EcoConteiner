## 🌎 Sobre o projeto

O EcoConteiner Casas é um sistema web que apresenta uma
proposta de moradias sustentáveis construídas a partir
do reaproveitamento de contêineres.

A plataforma permite consultar modelos de casas, visualizar
suas características e registrar solicitações de orçamento.

## 🎯 Objetivo

Apresentar alternativas de moradia sustentável através
de uma plataforma digital moderna, acessível e intuitiva.

## ⚙️ Funcionalidades

- Catálogo de modelos de casas.
- Consulta de características.
- Formulário de solicitação de orçamento.
- Validação de dados.
- Cálculo de estimativas.
- Armazenamento local das solicitações.
- Painel demonstrativo de consulta.
